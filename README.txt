Sarthak Singhal Portfolio

How to use:
1. Open index.html in a browser.
2. Replace the placeholder email with your real email.
3. Replace GitHub/LinkedIn links with your profiles.
4. Add real project GitHub links where the Project buttons are.
5. Add your resume link when ready.

Deploy:
- GitHub Pages: upload index.html and style.css to a repository, then enable Pages.
- Netlify: drag the folder into Netlify Drop.
